# 🚀 PySlim AI - The Ultimate 4-in-1 AI Developer Tool

PySlim AI is an all-in-one, full-stack AI platform designed for developers. It combines Code Generation, General Chat, Image Generation, Video Generation, and PDF Analysis into a single, sleek, dark-themed interface.

## ✨ Key Features

- **💻 Code Master:** Generates ultra-concise, production-ready code. It uses a Multi-Agent system (Generator + Critic) with strict anti-bloat rules to ensure the code is short and clean, unlike other LLMs.
- **💬 General Chat:** A fast, streaming chatbot that answers questions in Roman Urdu/English.
- **🎨 Image Generation:** Creates high-quality images from text prompts using Pollinations AI.
- **🎬 Video Generation:** Generates short cinematic videos using the Magic Hour API.
- **📂 File Upload (RAG):** Attach PDFs or Text files and ask questions based on their content.
- **🔐 Authentication:** Secure JWT-based login and signup with SQLite database.
- **💾 Local Chat History:** Saves your previous chats in the browser with options to edit or delete them.
- **🎨 Monaco Editor:** A VS Code-like syntax-highlighted editor for generated code.
- **⚡ Streaming Responses:** Word-by-word typing effect just like ChatGPT.

## 🛠️ Tech Stack

- **Frontend:** React.js, Vite, Monaco Editor, React-Markdown
- **Backend:** FastAPI, Python, LangChain, SQLite
- **AI Integrations:** Cerebras (Llama 3), Pollinations AI, Magic Hour
